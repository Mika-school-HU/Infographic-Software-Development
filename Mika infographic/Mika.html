6 Most Wanted Skills

1. Data Structuren en Algoritmen

Het is belangrijk om te weten hoe je data gestructureerd houdt en gebruiken kan.

2. Programmeertalen

Om een software developer te worden moet je op zijn minst 1 programmeertaal kunnen. Dit zijn de top 12 talen:

  1. Python
  2. Java
  3. JavaScript
  4. C#
  5. C en C++
  6. Kotlin
  7. Ruby
  8. PHP
  9. Swift
  10. Go
  11. TypeScript
  12. HTML & CSS

3. Source Control

Managen van code en version control en tools zoals Git, Mercurial en SVN.

4. Text Editors en IDEs

Essentieel als het gaat om developen. Het is belangrijk dat je een productieve ontwikkelaar wordt. Elke programmeur zou moeten weten hoe ze code in een IDE schrijven, compilen, runnen en belangrijk: debuggen.

5. Databases

Kunnen werken met databases is essentieel. Zonder database is de applicatie of software niet compleet.

6. Operating System (OS)

Het is belangrijk dat je weet hoe je OS werkt. Dan is het makkelijker om issues op te lossen.

  • Websites en webshops: via browser
  • Bedrijfssoftware: administratie, voorraad, klantgegevens

Wat doe je?

  • Ontwerpen
  • Bouwen

Wildcard (wat vind jij belangrijk)?

  • Up to date blijven met de ontwikkelingen
  • Communicatie en samenwerking

Baby Roadmap (Junior 0-5 jaar)

Stap 1

  • Een programmeertaal leren
  • Syntax, loops, variabelen, functies en datastructuren leren
  • Versiecontrol en Git en GitHub

Stap 2

  • Leer hoe de protocollen werken (HTTP/HTTPS requests, DNS, networking, API)
  • Relaties in databases en queries
  • Frameworks (React.js (frontend), Node.js (backend), Laravel, ASP.NET Core)
  • Basisbeveiliging (FTP, injectie-aanvallen vermijden, wachtwoorden beheren)
  • SAST (Static Application Security Testing) en DAST (Dynamic Application Security Testing)

Stap 3

Leren omgaan met opdrachtgevers

  • Plan opzetten
  • POC (proof of concept)
  • Terugkoppelen aan opdrachtgever (is alles naar wens, etc.)
  • Presenteren van eindproduct
