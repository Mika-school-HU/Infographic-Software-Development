6 Most Wanted Skills

2. Programmeertalen

3. Source Control

Managen van code en version control met tools zoals Git, Mercurial en SVN.

4. Text Editors en IDE's

Code schrijven, compilen, runnen en debuggen in een IDE.

5. Databases

Weten hoe je OS werkt maakt issues oplossen makkelijker.
